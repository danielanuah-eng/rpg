# Fonte de assets 3D

Repositório: https://github.com/arielshad/3d-asset-server.git

Clone local: `.sources/3d-asset-server`.

Branch: `main`.

Commit conectado: `c5c408d1eb524e3bf878bb63ff47bc928980bf76`.

Este repositório contém um serviço de busca e download de modelos, materiais e texturas, com API e MCP. O clone está disponível para integração futura; o serviço ainda não foi instalado ou iniciado e nenhum asset foi importado para o jogo.

Para atualizar o clone, abra um terminal na pasta ArenaTatica e execute:

```powershell
git -C .sources/3d-asset-server pull --ff-only
```

A pasta `.sources/` está ignorada no Git do jogo e mantém o histórico remoto independente. Consulte o README do serviço para instalação e a licença de cada asset antes de sua utilização.
