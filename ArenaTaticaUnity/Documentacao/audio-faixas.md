# Áudios gravados da Arena (pedido de 22/10)

Arquivos .ogg/.wav/.mp3 em `Assets/ArenaTatica/Resources/`. O nome sem extensão é a chave. Se o arquivo faltar, o jogo usa o padrão.

## Trilhas por Modo da L.E.L.A (`Audio/Musica/<estilo>`)
Substituem a trilha sintetizada enquanto alguém está no Modo. O Pulse sobe o tom delas também.

| Arquivo | Modo |
|---|---|
| `Audio/Musica/ansiedade` | Ansiedade |
| `Audio/Musica/guerra` | Guerra |
| `Audio/Musica/calma` | Calma |
| `Audio/Musica/alegria` | Alegria |
| `Audio/Musica/ira` | Ira |

## Falas e efeitos por skill (`Audio/Skills/<id da skill>`)
Tocam uma vez quando a skill é usada.

| Arquivo | Quem / skill |
|---|---|
| `Audio/Skills/invocacao-dragao` | Ciantia, Dragão Azul (invocação) |
| `Audio/Skills/dragao-dourado` | Ciantia, Dragão Dourado |
| `Audio/Skills/prisao-dos-pesadelos` | Príncipe Kellen, prender |
| `Audio/Skills/black-hole` | Pele D. N, Black Hole |

Qualquer outra skill ganha som do mesmo jeito: basta pôr o arquivo com o id dela.
