# Acesso do Claude pelo GitHub

Esta pasta copia o pacote de procedimentos do encerramento aprovado. A ENTRADA.md original descreve a biblioteca local de Enzo, cujos objetos deduplicados e índice permanecem nessa biblioteca.

Os assets finais entregues no repositório estão em [imagens](../../imagens/), relacionados em [progresso.json](../../progresso.json). Prompts e decisões ficam em [registros](../../registros/), incluindo [aprovação final](../../registros/aprovacao-final-2026-10-03.json). Versões anteriores ficam em [versoes-anteriores](../../versoes-anteriores/).

Para integração do TCG, usar também [catálogo de artes para cartas](../../../cartas/catalogo-artes.json) e [protocolo do Designer](../../../cartas/COORDENACAO-CLAUDE.md). Os scripts deste pacote são snapshots; os scripts operacionais ficam na pasta de arte original. O caminho absoluto da biblioteca local não é requisito para o Claude consumir as imagens entregues pelo GitHub.
